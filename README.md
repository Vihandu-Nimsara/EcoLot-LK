# EcoLot LK — Plain PHP MVC Initial Structure

This starter follows the university requirement of **no frameworks and no external libraries**.

## Allowed stack
- Plain PHP
- MySQL
- HTML
- CSS
- Vanilla JavaScript
- Custom MVC structure
- PDO

## Not included
- Laravel
- CodeIgniter
- React
- Vue
- Angular
- Bootstrap
- Tailwind
- jQuery
- Composer packages

## Current state
This ZIP contains only the clean initial project structure and starter files.
Business modules will be implemented step by step.

## Suggested local location
`xampp/htdocs/ecolot-lk/`

## Entry point
`public/index.php`
